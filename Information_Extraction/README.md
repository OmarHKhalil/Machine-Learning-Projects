# Information Extraction and Product Classification

## Overview

This project implements an integrated analytical engine for classifying items extracted from optical character recognition (OCR) processes. It maps raw text generated by OCR models to specific financial and product categories, ensuring the accuracy of subsequent financial analysis and recommendations. The system uses a Multi-Layer Perceptron (MLP) neural network classifier as the primary model, leveraging TF-IDF vectorization for text representation and strategic data preprocessing techniques.

## Project Architecture

The entire lifecycle of this classification component, from data definition and balancing to model deployment, follows a comprehensive pipeline:

```
Raw OCR Text
    ↓
Data Preprocessing & Cleaning
    ↓
TF-IDF Vectorization & Encoding
    ↓
Data Balancing (RandomOverSampler)
    ↓
Model Training (MLP Classifier)
    ↓
Model Evaluation & Deployment
```

## Dataset Information

### Dataset Source

- **Dataset**: ReceiptSense
- **Total Records**: 13,323 rows
- **Primary Columns**: Item_Name and class (15 product categories)

### Dataset Structure

The system processes the following columns:

- `Item_Name`: Product name/description
- `class`: Product category (target variable)
- `Brand`: Product brand
- `Weight`: Product weight
- `Number of units`: Quantity units
- `Size of units`: Unit size measurement
- `Price`: Unit price
- `T.Price`: Total price
- `Pack`: Package type
- `Unit`: Measurement unit

### Product Categories (15 Classes)

The system classifies products into the following categories:

1. **Beverages** - Soft drinks, juices, water, tea, coffee, hot drinks
2. **Bakery & Breakfast** - Bakery items, biscuits, cakes, cereals, breakfast bars
3. **Snacks & Sweets** - Chips, crackers, chocolates, sweets, desserts
4. **Home & Furniture** - Furniture and home appliances
5. **Fruits & Vegetables** - Fresh produce, vegetables, herbs, fruits
6. **Meat & Poultry** - Beef, lamb, processed meat, poultry
7. **Household & Cleaning** - Cleaning supplies, laundry products, detergents
8. **Pantry & Cooking Ingredients** - Rice, pasta, pulses, cooking ingredients
9. **Dairy & Eggs** - Milk products, cheese, eggs
10. **Personal Care** - Skin and body care, hair care, soap
11. **Baby Products** - Baby care items
12. **Office & Stationery** - Office supplies and stationery items
13. **Electronics** - Mobile devices, tablets, electronic devices
14. **Fast Food** - Fast food items and prepared meals
15. **Juices & Cocktails** - Specialized juice and cocktail beverages

## Data Preprocessing

### 1. Data Structure Preparation

A comprehensive set of columns was adopted to ensure accurate data extraction and feature engineering.

### 2. Data Cleaning

- Removal of missing values (NaN)
- Filtering of irrelevant categories (e.g., "Party supplies and gifts")
- Data validation and quality checks

### 3. Numerical Transformation

#### TF-IDF Vectorization

- **Purpose**: Convert textual product names to numerical feature vectors
- **Parameters**:
  - Captures the importance of words within products
  - Generates sparse or dense matrices based on configuration

#### One-Hot Encoding

- **Purpose**: Encode target categories into numerical format
- **Parameters**:
  - `sparse_output=False`: Returns dense matrix for faster processing
  - `handle_unknown='ignore'`: Safely handles unseen categories during inference

### 4. Data Balancing

- **Method**: RandomOverSampler (ROS)
- **Purpose**: Address class imbalance in the dataset
- **Parameters**: `random_state=42` (ensures reproducibility)
- **Effect**: Equalizes the distribution of minority classes

## Model Comparison

Four machine learning algorithms were evaluated during the development phase:

### 1. Linear Support Vector Machine (LinearSVC)

- **Purpose**: High-dimensional text classification
- **Architecture**: One-vs-Rest multi-class strategy
- **Parameters**:
  - `C=1.0`: Regularization strength
  - `dual='auto'`: Automatic solver selection
  - `random_state=42`: Reproducibility
  - `max_iter=2000`: Maximum iterations for convergence

### 2. Multi-Layer Perceptron (MLPClassifier) **SELECTED**

- **Purpose**: Neural network learning complex non-linear relationships
- **Architecture**: Feed-forward network with hidden layers
- **Parameters**:
  - `activation='relu'`: ReLU activation function
  - `learning_rate='constant'`: Fixed learning rate
  - `early_stopping=True`: Prevents overfitting
  - `alpha=0.01`: L2 regularization strength
  - `max_iter=300`: Maximum training epochs
  - `random_state=42`: Reproducibility

### 3. K-Nearest Neighbors (KNN)

- **Purpose**: Similarity-based classification
- **Parameters**:
  - `n_neighbors=11`: Number of neighbors for voting
  - `weights='distance'`: Distance-weighted voting
  - `metric='cosine'`: Cosine distance for semantic similarity

### 4. Random Forest Classifier

- **Purpose**: Ensemble learning with decision trees
- **Parameters**:
  - `n_estimators=500`: Number of trees in the forest
  - `max_depth=None`: Unlimited tree depth
  - `min_samples_split=2`: Minimum samples required to split
  - `min_samples_leaf=1`: Minimum samples required at leaf
  - `max_features='sqrt'`: Number of features for splitting
  - `class_weight='balanced'`: Fair classification across categories
  - `random_state=42`: Reproducibility
  - `n_jobs=-1`: Parallel processing on all cores

## Model Performance

### Evaluation Metrics

The MLP model was rigorously verified using the following metrics:

1. **Accuracy**: Overall correctness of classifications
2. **Precision**: Proportion of true positives among predicted positives
3. **Recall**: Proportion of true positives among actual positives
4. **Weighted F1-Score**: Harmonic mean of precision and recall, weighted by class support

### Results Summary

The **MLP Classifier** demonstrated superior performance in balancing response speed and classification accuracy, making it the chosen model for deployment.

#### Key Performance Indicators:

- Consistent high accuracy across all 16 product categories
- Balanced precision and recall preventing class-specific biases
- Reliable weighted F1-scores ensuring overall reliability

## Deployment

### Model Serialization

The entire processing pipeline has been serialized into a single file for deployment efficiency:

**File**: `Model/MLP_Model.joblib`

**Included Components**:

- TF-IDF vectorizer for text transformation
- Label encoder for category mapping
- Trained MLP neural network classifier

### Pipeline Integration

All preprocessing steps (vectorization, encoding) and the MLP model are packaged together, enabling:

- Seamless inference on new product data
- Consistent preprocessing across training and production environments
- Reduced model loading time and memory footprint
